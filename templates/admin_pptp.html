Requirements and safety

  • The PPTP server must be enabled on the CCR, and each username must have an active PPP secret.
  • TCP port 1723 and GRE (IP protocol 47) must be allowed between the Ubuntu server and the CCR.
  • Each tunnel uses its own Linux interface/peer. Routes for that connection's subnets are installed through its tunnel interface.
  • Existing routes for identical or overlapping subnets on other interfaces may cause conflicts. The manager should detect conflicting routes and prevent installation of those routes.
  • PPTP is deprecated and insecure. For production environments, use WireGuard or IPsec where possible.
